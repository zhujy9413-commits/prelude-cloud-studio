# 序幕 Prelude

电脑端优先的本地 AI 短镜头工作室。用户输入一句描述、选择内置首帧，或上传自己的参考图，生成 2–15 秒视频。页面采用电影感云海、渐变星空与玻璃面板。

## 当前状态

真实文生视频已跑通生成、保存、播放和下载。2026-10-26 已完成内置雨夜首帧 8 秒实测，以及自传月光海岸首帧 5 秒实测，均为 1280×720，浏览器整段播放、下载及作品详情通过。两条样本不代表所有题材的生成质量。当前仅本机运行，没有账号、支付、跨设备同步或公网部署。

支持创作工作台、规则时长建议、真实任务等待、刷新恢复、作品搜索筛选、命名、收藏、最近删除、恢复、详情与复用。静态概念图有独立标识；选择“按此画面生成”才会向模型传入对应图片。自传首帧支持 JPG、PNG、WebP，最大 10MB，可选择或拖入、预览大图；画幅跟随图片。上传本身不调用视频模型。

选好首帧后，可通过“帮我写动作”填写主体运动、选择镜头与节奏，并预览组合后的描述。确认才写入输入框，支持撤销和继续编辑，手动时长保持原值。引导使用本地规则，不识别图片或调用生成模型。

## 本地运行

需要 Python 3.10+ 和 Pillow；无需前端构建。

```sh
python3 -m venv .venv
.venv/bin/python3 -m pip install -r requirements.txt
cp .env.example .env.local
chmod 600 .env.local
# 在本机编辑配置，填入自己的百炼北京地域 Key 与对应主机名
.venv/bin/python3 server.py
```

打开 http://127.0.0.1:4173 。macOS 也可双击“启动序幕.command”。保持服务运行；已启动时无需重复启动。直接双击 dist/index.html 或普通静态预览不能真实生成。

产品访问链接统一使用以上首页入口；从首页进入创作或“我的作品”，不默认打开工作台或成片详情。

密钥仅保存在服务端。自由文字使用 wan2.6-t2v；内置和自传首帧使用 wan2.6-i2v-flash。当前固定 720P；首帧为有声，内置图为 16:9，自传图保持原比例；自由文字支持横屏、竖屏和方形。

## 成本和恢复

北京公开标价：当前文生 0.60 元/秒，首帧有声 0.30 元/秒；免费额度、优惠和实扣以账号为准。服务默认每日预留标价不超过 30 元，全局同时一条任务，不自动充值。PRELUDE_DAILY_LIMIT_CENTS 可设置本地预算，单位分，范围 300–30000。

任务、参考图与结果存于 .studio，按当前浏览器会话隔离。参考图经校验、方向修正、缩放及移除元数据后保存为 JPEG；详情可查看生成时实际使用的首帧。刷新、重启继续处理原任务；提交结果不明时保留记录并阻止自动重发。删除只是移入最近删除，保留视频和参考图，可恢复。清除 Cookie 或换浏览器后旧作品不会自动出现在新会话。
