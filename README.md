# 序幕 Prelude

电脑端优先的本地 AI 短镜头工作室。用户输入一句描述、选择内置首帧，或上传自己的参考图，生成 2–15 秒视频。页面采用电影感云海、渐变星空与玻璃面板。

## 当前状态

真实文生视频已跑通生成、保存、播放和下载。2026-10-26 已完成内置雨夜首帧 8 秒实测，以及自传月光海岸首帧 5 秒实测，均为 1280×720，浏览器整段播放、下载及作品详情通过。两条样本不代表所有题材的生成质量。2026-10-27 补齐邀请通行证、登录找回作品和个人时长额度，并开启本机经 Cloudflare 临时 HTTPS 链接的好友试用。尚未部署腾讯云或实现支付。

支持创作工作台、规则时长建议、真实任务等待、刷新恢复、作品搜索筛选、命名、收藏、最近删除、恢复、详情与复用。静态概念图有独立标识；选择“按此画面生成”才会向模型传入对应图片。自传首帧支持 JPG、PNG、WebP，最大 10MB，可选择或拖入、预览大图；画幅跟随图片。上传本身不调用视频模型。

选好首帧后，可通过“帮我写动作”填写主体运动、选择镜头与节奏，并预览组合后的描述。确认才写入输入框，支持撤销和继续编辑，手动时长保持原值。引导使用本地规则，不识别图片或调用生成模型。

## 本地运行

需要 Python 3.10+ 和 Pillow；无需前端构建。

```sh
python3 -m venv .venv
.venv/bin/python3 -m pip install -r requirements.txt
cp .env.example .env.local
chmod 600 .env.local
# 在本机编辑配置，填入自己的百炼北京地域 Key 与对应主机名
.venv/bin/python3 server.py
```

打开 http://127.0.0.1:4173 。macOS 也可双击“启动序幕.command”。保持服务运行；已启动时无需重复启动。直接双击 dist/index.html 或普通静态预览不能真实生成。

产品访问链接统一使用以上首页入口；从首页进入创作或“我的作品”，不默认打开工作台或成片详情。

密钥仅保存在服务端。自由文字使用 wan2.6-t2v；内置和自传首帧使用 wan2.6-i2v-flash。当前固定 720P；首帧为有声，内置图为 16:9，自传图保持原比例；自由文字支持横屏、竖屏和方形。

## 播放与下载

2026-10-28：原片保留，使用本地 FFmpeg 生成流畅播放版与静态封面。已有 15 秒样本从 18.25MB 降为 4.51MB，仍为 1280×720/30fps；压缩有画质取舍，原片逐字节不变。界面可分别下载流畅版与原片，作品列表不再并发加载多个 MP4。首页云海降为约 0.85MB，增加停滞恢复；播放成片时暂时停止背景。此为文件体积优化，不保证任意网络都不会缓冲，人物生成质量仍需单独验证。

校验与编码使用忽略的 `.tools/ffmpeg`、`PRELUDE_FFMPEG` 或系统 FFmpeg。新任务须有可执行的 FFmpeg；原片通过完整校验后，加工失败可回退原片，不重发模型任务。

## 内测通行证

启动服务后，用以下本机命令创建一次性邀请。默认 30 秒个人总额度、7 天开通有效期；邀请码只写入被 Git 忽略的 `.studio/invitations/` 私有文件，不在终端、网页接口或仓库公开。

```sh
.venv/bin/python3 access_admin.py invite --seconds 30 --days 7
.venv/bin/python3 access_admin.py list
```

从首页右上角“内测通行证”进入“首次使用”，填写邀请码、通行名和自己设置的 12–128 字符密码。首次开通会绑定当前浏览器已有的视频与参考图，历史任务不占用新发放额度。之后在同一后端用通行名和密码登录，即可访问绑定作品；朋友使用临时 HTTPS 首页，127.0.0.1 地址只供本机使用。新地址不会继承旧 Cookie，已有通行证须选择“已有通行证”重新登录。登录现有账户不会合并其他匿名会话作品；未绑定的上传图需要重新选择。草稿和镜头方案仍是浏览器本地数据，不跨设备同步。

默认 `PRELUDE_INVITE_ONLY=1`，未登录不能上传或修改作品、创建生成。每次提交按所选秒数预留个人额度，明确失败或拒绝释放，成功、待核对和最近删除均保留占用；不是按次数计费，也不代替供应商账单。每日全局标价预算及单活动任务保护同时生效。额度用完联系邀请人，不自动加额。

管理员可在本机使用 `access_admin.py allowance 通行名 30` 设置累计总额度（不清空已用时长）；`revoke 邀请编号` 撤销未使用邀请；`reset-password 通行名` 在终端隐蔽输入新密码并退出该账户所有设备。没有邮件或短信找回。密码带独立随机盐，经 PBKDF2-HMAC-SHA256 600,000 轮处理，不存明文；登录有持久限速，登录和退出轮换 Cookie，写操作仍校验同源与 CSRF。

## 成本和恢复

北京公开标价：当前文生 0.60 元/秒，首帧有声 0.30 元/秒；免费额度、优惠和实扣以账号为准。服务默认每日预留标价不超过 30 元，全局同时一条任务，不自动充值。PRELUDE_DAILY_LIMIT_CENTS 可设置本地预算，单位分，范围 300–30000。

任务、参考图与结果存于 .studio，登录后按通行证隔离；未绑定的旧作品仍按原浏览器会话隔离。参考图经校验、方向修正、缩放及移除元数据后保存为 JPEG；详情可查看生成时实际使用的首帧。刷新、重启继续处理原任务；提交结果不明时保留记录并阻止自动重发。删除只是移入最近删除，保留视频和参考图，可恢复。清除 Cookie 后可重新登录找回已绑定作品；未绑定作品仍无法自动找回。

成片下载检查响应长度和 MP4 结构，再完整解码视频与音轨、检查时长及文生画幅，通过后才显示成功。未通过的文件保留在私有 quarantine，重新获取同一原任务的结果；连续三次恢复未果转人工核对，不重复生成。有编号的待核对作品可点击“重新查询原任务”，无编号时将作品编号交给邀请人。管理员先在百炼确认结果，再使用 `task_admin.py list` 和 `resolve`（用 `--help` 查看）；可绑定原任务、确认未提交/失败，或记录已生成但不可获取。核对按作品加锁并留下记录；已生成但不可获取保留已用额度，只有明确未提交/失败才释放。

## 临时分享给朋友

采用 [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)，临时链接无固定域名、不购买服务器。本机必须持续开机联网，合盖、关机或关闭连接会中断访问。连接启动期间使用 macOS `caffeinate -i` 防止空闲睡眠，不修改系统长期设置。临时入口经 Cloudflare 转发，首页可公开访问，上传、生成和私人作品仍需邀请通行证。

`share_studio.py` 共用现有数据与单个生成工作者：4173 供本机访问，4181 仅接受指定临时域名的 HTTPS 转发；两个端口均只监听 127.0.0.1。正式开启前要求最近一天的独立模拟公网验证通过；切换前先结束活动任务、停止旧服务，完成私有备份，最后启动分享，不能同时备份和启动。管理命令为 `.venv/bin/python3 share_studio.py start|status|stop`。需要额外安装 `requirements-production.txt` 及官方可信来源校验后的 `.tools/cloudflared`；本机当前使用已校验的 Homebrew core 2026.10.4 版本与 QUIC 连接。

当前首页地址与运行日志只记录在被 Git 忽略的 `.studio` 内。双击“停止临时分享.command”可关闭临时公网入口，保留本机工作室；整个分享管理进程结束则同时停止其本机后台。重开地址通常改变，需重新通知朋友，但同一数据目录中的通行证、额度与作品继续保留。私人邀请文件由邀请人逐一转交，不放入网页或仓库。本次创建 3 份 30 秒、7 天内开通的一次性邀请，未代设朋友密码。

临时连接不提供正式托管的稳定性，朋友所在网络的可达性需实际打开验证。生成仍消耗百炼额度或余额；本次网络测试只使用 FakeProvider，未新增真实生成。
