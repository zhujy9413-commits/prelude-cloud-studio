# 序幕 Prelude

电脑端优先的本地 AI 短镜头工作室。用户输入一句描述，或选择内置参考首帧，生成 2–15 秒视频。页面采用电影感云海、柔和字体与玻璃面板。

## 当前状态

真实文生视频已跑通生成、保存、播放和下载。新增首帧模式完成接口与浏览器模拟验证，真实视觉效果待验收。当前仅本机运行，没有账号、支付、跨设备同步或公网部署。

支持创作工作台、规则时长建议、真实任务等待、刷新恢复、作品搜索筛选、命名、收藏、最近删除、恢复、详情与复用。静态概念图有独立标识；选择“按此画面生成”才会向模型传入对应图片。

## 本地运行

需要 Python 3.9+，使用标准库，无额外后端依赖或前端构建。

```sh
cp .env.example .env.local
chmod 600 .env.local
# 在本机编辑配置，填入自己的百炼北京地域 Key 与对应主机名
python3 server.py
```

打开 http://127.0.0.1:4173 。macOS 也可双击“启动序幕.command”。保持服务运行；已启动时无需重复启动。直接双击 dist/index.html 或普通静态预览不能真实生成。

密钥仅保存在服务端。自由文字使用 wan2.6-t2v；内置首帧使用 wan2.6-i2v-flash。当前固定 720P；首帧为有声、16:9；自由文字支持横屏、竖屏和方形。

## 成本和恢复

北京公开标价：当前文生 0.60 元/秒，首帧有声 0.30 元/秒；免费额度、优惠和实扣以账号为准。服务默认每日预留标价不超过 30 元，全局同时一条任务，不自动充值。PRELUDE_DAILY_LIMIT_CENTS 可设置本地预算，单位分，范围 300–30000。

任务与结果存于 .studio，按当前浏览器会话隔离。刷新、重启继续处理原任务；提交结果不明时保留记录并阻止自动重发。删除只是移入最近删除，保留视频，可恢复。清除 Cookie 或换浏览器后旧作品不会自动出现在新会话。
