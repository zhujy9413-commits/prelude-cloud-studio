# 序幕产品需求文档 PRD

版本：2026-10-27 本地内测基础版。本文供后续开发和验收使用，范围为电脑端短镜头创作、等待成片、作品管理及邀请身份。现有能力以代码和测试为准，内置雨夜及自传海岸首帧已各完成一次真实验收，更多输入的质量仍待验证。

## 产品目标与信息结构

用户从首页或工作台输入一句描述，确定模式、画幅和时长，提交后看到真实进度，最终获得可播放下载的视频。首页承担品牌展示和快速开始；工作台承担持续创作和作品管理；灵感区区分概念静帧与真实视频。

电脑端优先，较窄屏改为上下布局。固定导航支持开始创作、灵感片场、我的作品和我的工作室，锚点留出导航高度。首页生成卡片居中，文字位于上方，保留云海空间。

## 创作输入

**R01 文字模式。** 提示词去除首尾空白后为 1–1200 字。画幅可选 16:9、9:16、1:1，目标清晰度 720P。非法输入在提交前提示，后端再次校验，不能靠绕过前端提交不合法参数。

**R02 参考首帧模式。** 内置云海、雨夜东京、月面漫游示例的“按此画面生成”将对应图片带入创作区，显示缩略图和运动提示词。内置来源为 cloud、city、lunar 三个枚举，画幅锁定 16:9，后端从公共素材读图并传给图生接口。不得接受任意路径或远程 URL。前后端通过 reference_supported 确认能力，旧服务不应静默降级成纯文字。

**R02a 自传首帧。** 在首页和工作台支持选择或拖入 JPG、PNG、WebP，最大 10MB。服务端校验实际格式、尺寸、单帧和归属，修正方向、去除元数据后保存私有副本；上传不生成视频。创作区显示文件名、尺寸与缩略图，点击可预览大图，画幅跟随图片锁定。用户输入动作描述、确认时长与估价后才生成；上传中禁用提交和参考切换，失败保留此前有效输入。旧服务未声明 upload_supported 时禁用入口。

**R02b 动作描述引导。** 选好首帧后显示“帮我写动作”入口，按需打开原图与引导并列的面板。用户填写图中已有主体的动作，选择固定、推进、拉远或跟随镜头，以及舒缓、适中或明快节奏；预览本地组合的完整描述。空动作不能写入，取消不改变原文；已有文字时明确提示替换，写入后支持撤销，手动编辑或更换首帧后清理旧撤销记录。写入刷新字数及规则时长建议，保留手动时长，不自动生成。内置示例提供对应动作灵感，自传图使用通用建议，不宣称已识别图片。

**R03 模式切换。** “改为文生视频”移除参考，解锁画幅并更新估价。未编辑的示例运动文案可恢复对应文字描述；已编辑的用户输入保留。草稿保留参考选择和上传元数据，刷新后重新校验图片归属；失效时明确提示重新上传，不能静默变为文生。旧草稿与旧作品不会自动变成图生模式。新镜头保持空白结果，不自动选中上一条成片。

**R04 时长。** 用户可输入 2–15 的整数秒，空框显示浅色 10。基于提示词的秒数、动作和节奏给出本地规则建议；手动值优先，空值才采用建议。点击采用建议才替换输入。不得宣称建议保证动作完整或调用了额外模型。

**R05 提交前反馈。** 展示有效时长、模式和标价估算。服务未配置、能力不支持、参数非法、已有活动任务或预算不足时给出对应原因。生成按钮有可识别的边界、悬停、按下和键盘焦点状态。

## 生成与等待

**R06 单次提交。** 每次新创作使用独立 request_id；同一标识及相同参数返回原任务。相同标识改变提示词、时长、画幅或参考时拒绝，其他会话不能复用该请求。网络不确定不能自动创建新任务。

**R07 状态表达。** 提交、排队、生成、保存节点来自后端状态，显示已等待时长，不伪造百分比或剩余时间。云海是氛围素材，应明确标识。关闭预览、标签页隐藏、离开区域或用户暂停动态时，停止不必要动画。

| 状态 | 用户含义 | 处理 |
| --- | --- | --- |
| SUBMITTING | 正在提交 | 等待当前请求，不重复点击生成 |
| PENDING | 上游排队 | 查询同一任务 |
| RUNNING | 正在生成 | 查询同一任务 |
| DOWNLOADING | 正在保存 | 下载原结果，失败不重新生成 |
| SUCCEEDED | 本地结果可用 | 准备首帧并切换成片 |
| FAILED 或 REJECTED | 生成失败或明确拒绝 | 显示原因，允许用户调整后主动发起新任务 |
| UNCERTAIN | 提交结果待核对 | 保留记录并阻止自动重发，核对供应商任务 |
| UNAVAILABLE | 原结果不可用 | 显示不可用状态并保留记录，不伪装完成 |

**R08 恢复。** 刷新或重启服务继续查询已有任务；提交未取得上游任务号即中断时标为待核对。已等待时长依据创建时间恢复，不从零计时。当前不提供取消正在执行的供应商任务。

**R09 成片过渡。** 保存完成后，视频首帧实际可显示才进行约 900ms 叠化。不要自动播放有声成片；加载失败显示播放错误，区分模型失败与文件加载失败。关闭详情停止播放。

## 作品管理

**R10 列表与筛选。** 展示当前通行证的真实作品；未绑定旧作品仍归原浏览器会话。支持搜索、全部、已完成、进行中、我的收藏和最近删除。选中分类有清晰底色和状态；缩略视频接近可视区域时再加载。新镜头、复用描述均不改写原任务。

**R11 命名与收藏。** 名称为去空白后 1–60 字，不接受控制字符；修改不改变原提示词。收藏状态保存到本机 SQLite，重启保持。原有概念方案仍使用浏览器本地存储，与真实成片有明确区别。

**R12 删除与恢复。** 删除移入最近删除，提供即时撤销及后续恢复；不删除视频文件，不自动清空。恢复保留收藏和原生成信息，不调用模型。生成中或待核对任务拒绝删除。最近删除中的视频不能播放下载，恢复后重新可用。

**R13 详情。** 显示成片、完整提示词、创建时间、画幅、时长、清晰度、实际模型、参考来源和标价估算，提供复制、继续调整、下载、收藏和删除。首帧作品显示生成时实际使用的参考图，上传图显示原文件名；“继续调整”同时恢复图片、描述和参数，返回原创作区，并提示修改后再主动生成。概念静帧入口保持“按此画面生成”，不增加独立调整模块。旧任务继续显示原文生模型。估算不能称为实际扣款。

R13 补充：详情新增默认折叠的“生成记录”，不增加创作主模块。新任务在提交前冻结实际模型、参数、原始与提交描述及指纹、首帧类型与字节指纹、记录时间和提交尝试时间；执行使用该冻结记录。详情按需展示扩写、镜头、显式 seed 与请求指纹。普通创作没有显式 seed 时如实显示由模型随机生成。历史作品没有完整快照时明确说明未完整记录，不按当前默认值补写；供应商不返回的扩写后文本不能宣称已经保存。名称、收藏、删除恢复不改生成记录。

## 视觉与交互标准

使用深蓝紫暮色、粉金地平线、真实云海视频和透明玻璃面板。首页及工作台固定标题使用轻字重现代无衬线，品牌中文和作品名保留衬线，正文与输入保证易读；展示文案不加不必要的句尾句号。灵感区渐变衔接夜蓝星空，星点位置固定并微闪。静态概念图明确标注，不能用其充当生成结果。

点击元素具备边框或底色、明确文案、悬停和按压反馈；说明文字维持次级层级。支持键盘焦点；输入和媒体保留原生指针，桌面装饰指针带短暂彗星尾迹，可操作区域变为实心箭头，触屏保留系统行为。动效开关和系统减少动态偏好均生效。

首页与工作台柔和转场并保留背景播放位置。真实云海循环为有限片段，暂停、离屏和异常时退回静帧；不能描述成实时无限生成。

## 数据与上线边界

密钥仅服务端读取，不进入 dist、GitHub 或接口返回。会话使用 HttpOnly Cookie，写接口校验 CSRF、同源和归属；静态服务只开放 dist，私有参考图和视频按会话对应身份校验访问。上传图每个归属身份最多 100 张、200MiB；移除输入首帧不清除历史。当前只监听 127.0.0.1，邀请身份已实现，公网服务和支付尚未实现。

本地标价预算默认每日 30 元、全局一条活动任务。未经确认不提升并发或自动充值。清除 Cookie 后，已绑定作品可在同一服务重新登录找回；未绑定匿名记录仍依赖原会话。

**R14 邀请通行证。** 首页与工作台各保留一个轻量入口；首次使用凭单次邀请码创建通行名及密码，后续用通行名和密码登录。开通与绑定已有视频、参考图在同一事务完成，不改变原提示词、视频、名称、收藏或删除状态。用户自己设置密码；不增加邮箱、短信或收费步骤。登录原账户不自动合并其他匿名作品，未绑定上传图需重新选择。草稿及镜头方案仍本地保存，退出或切换身份清理旧私有页面状态。没有邮件找回，忘记密码联系邀请人用本机管理工具重设。

**R15 个人限额。** 邀请默认发放累计 30 秒，界面展示剩余秒数和本次所需秒数；可由本机管理员调整总额。创建任务时服务端原子预留、幂等只计一次；明确失败或拒绝释放，成功、待核对及删除不释放。历史绑定作品不占用新发额度。超限说明剩余时长并允许缩短输入，不自动购买、加额或批量重试。现有全局预算和并发保护同时执行。

## 验收用例与未完成项

有效文字输入到真实成片播放下载，已完成真实验证。参考图选择到正确图像载荷、锁定画幅、移除恢复、费用变更、刷新保留和详情标记，已完成离线与浏览器验证。内置雨夜 8 秒和自传海岸 5 秒均已真实生成并完整播放下载，详细观察见测试报告。

邀请身份、会话恢复、作品归属及个人限额已通过离线与浏览器验证。仍需在受控预算下扩大首帧样本，检查不同场景的一致性、运动与闪烁，并以首次使用者验证完整创作任务。生产服务、HTTPS、异地访问、支付和运营尚未交付。
